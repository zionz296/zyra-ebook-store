ZYRA EBOOKS STORE - site estático (mesma arquitetura da Zyra Store)

COMO USAR
1. Hospede em GitHub Pages (ou Netlify, Vercel, Cloudflare Pages). Use um repositório SEPARADO, por exemplo "zyra-ebooks-store". Para testar localmente: python -m http.server
2. Abra o site com /#admin. Na primeira vez, crie a senha do administrador.
3. Cadastre ebooks (título, autor, formato, preço, descrição, detalhes e capa). A primeira imagem é a capa.
3b. LINK DE PAGAMENTO: no cadastro do ebook, preencha "Link da página de pagamento" com o checkout (Mercado Pago, Hotmart, Kiwify, Stripe etc.). Com o link, o botão vira "Comprar agora" e o cliente é levado ao pagamento. Sem o link, a compra segue pelo WhatsApp. Nunca use o link direto do arquivo do ebook.
4. Para os clientes verem o catálogo: Ebooks > "Exportar catálogo" e substitua o produtos.json no site publicado.

IMPORTANTE
- Venda apenas ebooks próprios ou com autorização/licença do titular dos direitos autorais.
- Custos e pedidos ficam só no navegador do administrador (nunca vão para o produtos.json).
- A senha protege apenas a tela neste navegador. Para segurança real e vários administradores, migre para Supabase.
- O arquivo do ebook NÃO fica no site: ele é enviado por e-mail/WhatsApp após a confirmação do pagamento.
- O número do WhatsApp está na constante WA, no início do script do index.html.
